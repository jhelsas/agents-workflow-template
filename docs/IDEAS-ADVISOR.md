# IDEAS — advisor-owned hypotheses and untested ideas

> **Owner.** Advisor. This is the advisor's append-only channel for
> hypotheses, untested ideas, and parked discussions that are **not active
> work**. Each dated entry carries the advisor's `Role:` trailer.
>
> **Contract.** Append-only; dated sections. Corrections are new entries
> that supersede, never edits. The advisor's standing channel remains
> `ADVISOR_NOTES.md`; this file holds idea proposals only.

---

## Entry format

```markdown
## YYYY-MM-DD — {{title}}

**Source:** {{a Finding in ADVISOR_NOTES | the owner's question | a session}}
**Status:** parked | proposed

**The idea.** {{the mechanism, stated precisely enough to be falsifiable}}

**What it would predict.** {{the observable signature if it is true}}

**The cheap falsifier.** {{the smallest experiment that could kill it}}

**Handed to:** the reviewer (for the IDEAS-REVIEWER cross-check) / the
planner (for compile consideration)

Role: advisor({{ADVISOR_MODEL}})
```
